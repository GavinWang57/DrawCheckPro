# DrawCheck Pro｜工程圖檢核專家

針對 CAD 匯出的機械工程圖 PDF：讓細線與細字變清楚，並在尺寸上做核對標記。
標記存在 PDF 旁邊的 `<檔名>.pdf.marks.json`，**不會修改原始 PDF**；每 30 秒自動存檔，關閉時也會自動儲存。
每個標記會記錄標記人（預設為電腦使用者，可在「設定」修改）與時間（格式：`2026-11-21 23:00:01`）。
開檔時若 PDF 內容與標記檔記錄的不同（SHA-256 比對），會提示圖面可能已改版。

> 軟體內的「設定 → 說明」（F1）有同樣內容；修改功能時請一併更新 `app/ui/manual.py` 與本檔。

## 畫面
- **上方工具列**：先點分類標籤，再顯示該類圖示
  - 檔案：開啟、最近檔案、儲存、匯出清單、匯出標記PDF、存標記頁面、列印
  - 檢視：適合頁面、適合頁寬、實際大小、放大、縮小、全螢幕
  - 工具：平移、選取、截圖
  - 審查：OK、NG、待確認、框選、圈選、文字、復原、重做
  - 設定：設定、說明
- **左側**：所有頁的縮圖、影像增強（可收合）
- **右側分頁**：屬性資訊、核對標記清單、搜尋
- 左右側欄按 « / » 可收合成窄邊條，點邊條上的圖示即可展開
- **底部**：換頁、適合頁面／頁寬、縮放滑桿與百分比

## 讓圖面更清楚（影像增強）
- **向量加粗（建議）**：線寬倍率、最小線寬、文字加粗、填色加粗
- **點陣加粗**：直接擴張畫面上的深色筆畫；向量處理失敗的頁面會自動改用此方式
- **顯示**：最細線像素、點陣擴張、加深可分別勾選；深色模式（D）
- 只影響顯示；輸出 PDF／列印時可另外選擇是否套用

## 審查標記
- **OK / NG / 待確認戳記**（C / X / Q）：點一下放置，戳記本身就代表狀態
- **框選 / 圈選**（R / E）：拖曳框住尺寸
- **文字**（T）：點一下輸入文字
- 框選、圈選、文字建立時為**無狀態**（純標記）；需要時用 1 / 2 / 3 設為 OK / NG / 待確認，用 0 改回無狀態。
  有狀態的文字框會在右下角顯示徽章（綠勾 OK、紅叉 NG、黃色問號待確認）
- 使用審查工具時按**右鍵**：快速切換為選取或其他審查工具；游標下有標記時也可直接改狀態、編輯、刪除
- 任何工具下按 **Esc**：回到選取工具
- 選取工具下可拖曳移動標記、拖曳空白處框選多個；雙擊或 Enter 編輯；Del 刪除

## 文字框
- 字級可直接輸入或從下拉選單選擇（pt）
- 字型：粗體、斜體、底線、雙底線、刪除線
- 文字顏色、底色（可設為透明）、框線顏色與粗細（下拉選單，可選無框線）；顏色皆可調透明度
- 可加上連結（網址或檔案）；設定視窗有即時預覽
- 滑鼠停在文字框上會出現工具列：開啟連結、編輯、複製一份、刪除；Ctrl+點擊也可開啟連結

## 搜尋
- Ctrl+F 或右側「搜尋」分頁，輸入時即時顯示結果；點選結果會跳到該位置並以橘色標示
- CAD 以線條繪製的文字（常見於尺寸數字）無法搜尋

## 截圖
- 工具 → 截圖（S）：先出現框線；拖曳框內移動、拉控制點調整大小、在框外拖曳重新框選
- 再按「複製到剪貼簿」或「另存 PNG」；Enter 或雙擊框內＝複製，Esc 取消
- 以至少 2 倍螢幕解析度重新渲染，包含加粗、深色模式與標記

## 輸出與列印
- **匯出清單**（Ctrl+E）：核對清單 xlsx / csv，含狀態、實測值、備註、文字內容與連結
- **匯出標記PDF**（Ctrl+Shift+E）／**存標記頁面**（Ctrl+Shift+S）：本頁或全部頁 → PDF
  （標記為向量，書籤依頁面列出每個標記，文字框連結可點），或 PNG（全部頁可合併成一張）
- **列印**（Ctrl+P）：本頁或全部頁；圖面方向會自動配合紙張
- 以上皆可選擇是否套用目前的加粗設定，且不會覆蓋原始 PDF
- PDF 中的文字使用系統的微軟正黑體（只嵌入用到的字）；找不到時改用內建字型，Ø 等符號可能缺字

## 開發
```
python -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python main.py [圖面.pdf]
.venv\Scripts\python -m pytest tests
```

### 封裝
程式圖示由 `tools\make_icon.py` 從 `icon.png` 裁切產生（需要 Pillow）。
```
powershell -ExecutionPolicy Bypass -File build.ps1
```
產出 `dist\DrawCheckPro.exe`（單一檔案，不需安裝 Python）。可以直接把 PDF 拖到 exe 上開啟。

安裝檔（需要 Inno Setup 6：`winget install --id JRSoftware.InnoSetup -e`）：
```
powershell -ExecutionPolicy Bypass -File build_installer.ps1
```
產出 `dist\DrawCheckPro-Setup-<版本>.exe`。預設安裝在使用者目錄，不需要系統管理員權限（安裝時也可以選擇改裝給所有使用者）。
可勾選建立桌面捷徑、加入 PDF 的「開啟檔案」選單（不會變更預設的 PDF 程式）。解除安裝時保留使用者設定。
使用者設定存在 `%APPDATA%\DrawCheckPro\DrawCheckPro.ini`。

### 圖面增強原理
- **向量加粗**：在記憶體副本中改寫內容串流，強制最小線寬（依 CTM 換算成實際 pt）、線寬倍率，
  並替文字和填色圖形加上同色描邊
- **點陣加粗**：渲染後用 min-filter 讓深色筆畫擴張
- **加深**：用 gamma 曲線讓反鋸齒產生的淺灰線條變深
- **深色模式**：反轉亮度但保留色相（紅線仍是紅線）
